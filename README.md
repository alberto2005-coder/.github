## English

Default community health files for all repositories owned by [@alberto2005-coder](https://github.com/alberto2005-coder).

GitHub automatically uses these files in any repository under this account that does not define its own. They are not copied into individual repositories, nor do they appear in clones or Git history—they live here in a single place.

### How to Override a File

If a specific repository needs its own version, simply add the file to that repository (in the root directory, `docs/`, or `.github/`). The local file takes precedence, and the default file here will no longer apply to that repository.

### Security

Do not report security vulnerabilities through public issues. Please use the private channel described in [`SECURITY.md`](SECURITY.md).

## Español

Archivos comunitarios por defecto para todos los repositorios de [@alberto2005-coder](https://github.com/alberto2005-coder).

GitHub utiliza estos archivos en cualquier repositorio de la cuenta que no tenga los suyos propios. No se copian en los repositorios, no aparecen en sus clones ni en su historial: se mantienen aquí, en un único sitio.

### Cómo sobrescribir un archivo

Si un repositorio necesita su propia versión, basta con añadir el archivo en ese repositorio (en la raíz, en `docs/` o en `.github/`). El archivo local tiene prioridad y el valor por defecto deja de aplicarse solo para ese repositorio.
