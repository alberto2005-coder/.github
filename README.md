# .github

Archivos comunitarios por defecto para todos los repositorios de [@alberto2005-coder](https://github.com/alberto2005-coder).

GitHub utiliza estos archivos en cualquier repositorio de la cuenta que no tenga los suyos propios. No se copian en los repositorios, no aparecen en sus clones ni en su historial: se mantienen aquí, en un único sitio.

## Contenido

| Archivo | Para qué sirve |
|---|---|
| [`SECURITY.md`](SECURITY.md) | Cómo reportar una vulnerabilidad de forma privada |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Cómo proponer cambios, abrir issues y enviar pull requests |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Normas de convivencia y canal de reporte |
| [`SUPPORT.md`](SUPPORT.md) | Dónde pedir ayuda y qué información incluir |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Plantillas de error y de propuesta de mejora |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Plantilla común para pull requests |

## Cómo sobrescribir un archivo

Si un repositorio necesita su propia versión, basta con añadir el archivo en ese repositorio (en la raíz, en `docs/` o en `.github/`). El archivo local tiene prioridad y el valor por defecto deja de aplicarse solo para ese repositorio.

No publiques vulnerabilidades en issues públicos. Usa el canal descrito en [`SECURITY.md`](SECURITY.md).
